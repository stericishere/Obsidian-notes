## 🎯 How to Use It

### **Step 1: Fill It Out**
Add items in each category:
- Life goals (short/medium/long term)
- Experiences to have
- Career milestones
- Skills to master
- Health goals
- Creative projects
- Learning goals
- Things to acquire

### **Step 2: Prioritize**
Mark most important with:
- ⭐ for top priority
- 🔥 for urgent/this year
- 📌 for scheduled

Example:
```
⭐ 🔥 Learn AI programming
📌 Travel to Japan (2026)
- Read 12 books this year
```

### **Step 3: Break Into Steps**
For big items, create an action plan:

**Goal:** Build AI SaaS Product
- [ ] Learn core concepts
- [ ] Build MVP
- [ ] Get first users
- [ ] Iterate & improve

### **Step 4: Track Progress**
When working on a goal:
- ✅ Check the box when completed
- 📝 Create a note about it
- 🎯 Move insight to appropriate domain
- 🔗 Link back to bucket list

### **Step 5: Celebrate**
When you complete something:
1. Move to "Completed" section
2. Date it: ✅ 2025-02-01 - Goal Name
3. Create a reflection note
4. Review monthly for wins

## 💡 Tips

### **Make Them Real**
- Specific, not vague (❌ "Be successful" → ✅ "Build app with 1000 users")
- Measurable (❌ "Learn coding" → ✅ "Complete Python course by June")
- Time-bound (❌ "Travel" → ✅ "Visit Japan in 2026")

### **Mix Big & Small**
- Big dreams (10+ years)
- Medium goals (1-5 years)
- Quick wins (this month)

### **Review Regularly**
- **Monthly:** Check 1-2 items
- **Quarterly:** Plan next 3 months
- **Yearly:** Assess year, plan next year

### **Connect to Learning**
Every bucket list item can become learning:
- Document the process
- Extract insights
- Add to relevant domain
- Build knowledge as you go

## 🔄 Weekly Review Integration

### **During Weekly Review:**

1. **Quick scan** of bucket list (2 min)
2. **Identify** any items related to your captures this week
3. **Link** your inbox notes back to bucket list items
4. **Check** if any items became action items for next week
5. **Update** progress on active goals

**Example:**
```
This week captured: "AI Agentic Workflows"
Relates to bucket list: "Learn AI Programming"
→ Link the Inbox note to bucket list
→ Move learning to 🔧 SYSTEMS
→ Update progress: 30% complete
```
