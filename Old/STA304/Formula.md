## Formula Sheet

| Formula                                                                                                                                     | Variables                                                                                                                                                                    | Conditions for Use                                                                                                                              | Result/Purpose                                                                               |
| :------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------- |
| **General Definitions & Sample Statistics**                                                                                                 |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $E(X) = \sum_{all x} x P(X=x)$                                                                                                              | $E(X)$: Expected value; $x$: possible value; $P(X=x)$: probability of $x$.                                                                                                   | General definition of Expected Value.                                                                                                           | Expected value $E(X)$.                                                                       |
| $\bar{y} = \frac{\sum_{i=1}^{n} y_i}{n}$                                                                                                    | $\bar{y}$: Sample mean; $y_i$: observation $i$; $n$: sample size.                                                                                                            | General calculation of the sample mean point estimate.                                                                                          | Sample mean estimate ($\bar{y}$).                                                            |
| $s^2_y = \frac{\sum_{i=1}^{n}(y_i - \bar{y})^2}{n-1}$                                                                                       | $s^2_y$: Sample variance; $y_i$: observation $i$; $\bar{y}$: sample mean; $n$: sample size.                                                                                  | General calculation of the sample variance.                                                                                                     | Estimated population variance, $s^2_y$.                                                      |
| **Simple Random Sampling (SRS) & Systematic Sampling**                                                                                      |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| CI for $\mu$: $\bar{y} \pm z_{\alpha/2} \sqrt{(1 - \frac{n}{N})\frac{s^2_y}{n}}$                                                            | $\mu$: population mean; $z_{\alpha/2}$: Normal quantile; $n$: sample size; $N$: population size; $s^2_y$: sample variance.                                                   | Used for the population mean $\mu$ under **SRS** or **Systematic Sampling**.                                                                    | Confidence Interval for the population mean $\mu$.                                           |
| HT Stat for $\mu$: $\frac{\bar{y} - \mu_0}{\sqrt{(1 - \frac{n}{N})\frac{s^2_y}{n}}}$                                                        | $\mu_0$: hypothesized mean; other variables as above.                                                                                                                        | Used for hypothesis testing the population mean $\mu$ under **SRS** or **Systematic Sampling**.                                                 | Test Statistic for $\mu$.                                                                    |
| CI for $p$: $\hat{p} \pm z_{\alpha/2} \sqrt{(1 - \frac{n}{N}) \frac{\hat{p}(1-\hat{p})}{n-1}}$                                              | $p$: population proportion; $\hat{p}$: sample proportion; other variables as above.                                                                                          | Used for the population proportion $p$ under **SRS** (using $\hat{V}(\hat{p})$).                                                                | Confidence Interval for the population proportion $p$.                                       |
| HT Stat for $p$: $\frac{\hat{p} - p_0}{\sqrt{(1 - \frac{n}{N}) \frac{\hat{p}(1-\hat{p})}{n-1}}}$                                            | $p_0$: hypothesized proportion; other variables as above.                                                                                                                    | Used for hypothesis testing the population proportion $p$ under **SRS**.                                                                        | Test Statistic for $p$.                                                                      |
| Sample Size $n$ for $\mu$: $n = \frac{\sigma^2 N}{\frac{B^2}{z^2_{\alpha/2}}(N-1) + \sigma^2}$                                              | $n$: required sample size; $\sigma^2$: population variance; $N$: population size; $B$: bound on error; $z_{\alpha/2}$: Normal quantile.                                      | Used to determine the sample size $n$ needed to estimate $\mu$ within bound $B$, applicable for **SRS** and **Systematic Sampling**.            | Required sample size $n$.                                                                    |
| Sample Size $n$ for $\tau$: $n = \frac{\sigma^2 N}{\frac{B^2}{N^2 z^2_{\alpha/2}}(N-1) + \sigma^2}$                                         | $\tau$: population total; $N$: population size; other variables as above.                                                                                                    | Used to determine the sample size $n$ needed to estimate $\tau$ within bound $B$, applicable for **SRS** and **Systematic Sampling**.           | Required sample size $n$.                                                                    |
| $\hat{\tau} = N\bar{y}$                                                                                                                     | $N$: population size; $\bar{y}$: sample mean.                                                                                                                                | Estimation of the population total $\tau$ under **SRS** or **Systematic Sampling**.                                                             | Point estimate of the population total $\tau$.                                               |
| $V(\hat{\tau}) = N^2 (1 - \frac{n}{N}) \frac{s^2}{n}$                                                                                       | $s^2$: sample variance; $n$: sample size; $N$: population size.                                                                                                              | Estimated variance of the population total $\hat{\tau}$ under **SRS** or **Systematic Sampling**.                                               | Estimated variance of the population total $\hat{\tau}$.                                     |
| **Stratified Random Sampling**                                                                                                              |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $\bar{y}_{st} = \sum_{h=1}^{H} W_h \bar{y}_h$                                                                                               | $\bar{y}_{st}$: stratified mean estimate; $W_h = \frac{N_h}{N}$: stratum weight; $\bar{y}_h$: sample mean in stratum $h$.                                                    | Used under **Stratified Random Sampling** to estimate the population mean.                                                                      | Point estimate of the population mean $\mu$.                                                 |
| $W_h = \frac{N_h}{N}$                                                                                                                       | $N_h$: population size in stratum $h$; $N$: total population size.                                                                                                           | Definition of stratum weight.                                                                                                                   | Stratum weight $W_h$.                                                                        |
| CI for $\mu$: $\bar{y}_{st} \pm z_{\alpha/2} \sqrt{\sum_{h=1}^{H} W^2_h (1 - \frac{n_h}{N_h}) \frac{s^2_h}{n_h}}$                           | $n_h$: sample size in stratum $h$; $N_h$: population size in stratum $h$; $s^2_h$: sample variance in stratum $h$.                                                           | Used for the population mean $\mu$ under **Stratified Random Sampling**.                                                                        | Confidence Interval for $\mu$.                                                               |
| Sample Size $n$ for $\mu$: $n = \frac{\sum_{h=1}^{H} N^2_h \sigma^2_h/a_h}{\frac{B^2 N^2}{z^2_{\alpha/2}} + \sum_{h=1}^{H} N_h \sigma^2_h}$ | $a_h$: allocation fraction/weight ($V_t$ or $V_t$ used for weights in source), depends on allocation method (Optimal, Neyman, Proportional); $\sigma^2_h$: stratum variance. | Used to calculate overall sample size $n$ for estimating $\mu$ in **Stratified Sampling** given a target bound $B$ and allocation method $a_h$. | Required sample size $n$.                                                                    |
| **Cluster Sampling**                                                                                                                        |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $v(\hat{T}_y) = K^2 (1 - \frac{k}{K}) \frac{s^2_T}{k}$                                                                                      | $v(\hat{T}_y)$: estimated variance of the total; $K$: total number of clusters; $k$: sampled clusters; $s^2_T$: variance among cluster totals.                               | Used for estimated variance of the total estimate $\hat{T}_y$ under **One-Stage Cluster Sampling**.                                             | Estimated variance of the total $\hat{T}_y$.                                                 |
| $s^2_T = \frac{1}{k-1} \sum_{i \in SC} (T_i - \hat{\mu}_T)^2$                                                                               | $T_i$: total of cluster $i$; $\hat{\mu}_T$: mean total of sampled clusters.                                                                                                  | Calculation of the variance among cluster totals.                                                                                               | Variance among cluster totals $s^2_T$.                                                       |
| **Ratio Estimation**                                                                                                                        |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $\rho = \frac{s_{xy}}{s_x s_y}$                                                                                                             | $\rho$: Correlation coefficient; $s_{xy}$: sample covariance; $s_x, s_y$: sample standard deviations of $X$ and $Y$.                                                         | Calculation of the sample correlation coefficient.                                                                                              | Sample correlation coefficient ($\rho$).                                                     |
| $\hat{V}(R) = (\frac{1-\frac{n}{N}}{n \mu^2_x}) s^2_r$                                                                                      | $s^2_r$: variance of the difference $(y_i - r x_i)$ squared (source,); $r = \bar{y}/\bar{x}$ (implied ratio estimate); $\mu_x$: population mean of ancillary $X$.            | Estimated variance of the ratio estimator $R$ (using SRS).                                                                                      | Estimated variance of $R$.                                                                   |
| **Regression Estimation**                                                                                                                   |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $\hat{\mu}_{y L} = \bar{y} + b(\mu_x - \bar{x})$                                                                                            | $\hat{\mu}_{y L}$: Regression estimate of $\mu_y$; $b$: slope coefficient; $\mu_x$: population mean of ancillary $X$; $\bar{y}, \bar{x}$: sample means.                      | Used for **Regression Estimation** of the population mean $\mu_y$ (using SRS).                                                                  | Estimate of the population mean $\mu_y$.                                                     |
| $b = \frac{\sum (y_i - \bar{y})(x_i - \bar{x})}{\sum (x_i - \bar{x})^2}$                                                                    | $b$: estimated slope; $y_i, x_i$: observations; $\bar{y}, \bar{x}$: sample means.                                                                                            | Calculation of the estimated slope coefficient $b$ for linear regression.                                                                       | Slope coefficient $b$.                                                                       |
| **Difference Estimation**                                                                                                                   |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $\hat{\mu}_{y D} = \mu_x + \bar{y} - \bar{x}$                                                                                               | $\hat{\mu}_{y D}$: Difference estimate of $\mu_y$; $\mu_x$: population mean of ancillary $X$; $\bar{y}, \bar{x}$: sample means.                                              | Used for **Difference Estimation** of the population mean $\mu_y$ (using SRS).                                                                  | Estimate of the population mean $\mu_y$.                                                     |
| **Logistic Regression**                                                                                                                     |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $\log (\frac{p}{1-p}) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_k x_k$                                                            | $p$: probability of event; $x_k$: independent variables; $\beta_k$: coefficients.                                                                                            | Used when modeling a **binary response variable** $Y$ (coded 0 or 1).                                                                           | Represents the log odds of the outcome occurring. Coefficients represent change in log odds. |
| **Post-stratification**                                                                                                                     |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $\hat{y}_{PS} = \frac{\sum_i \hat{y}_i \times N_i}{N}$                                                                                      | $\hat{y}_{PS}$: Post-stratification estimate; $\hat{y}_i$: estimate in cell $i$; $N_i$: population count in cell $i$; $N$: total population size.                            | Used for post-stratification to adjust sample estimates using known population/census counts ($N_i$) across demographic cells.                  | Population estimate $\hat{y}_{PS}$.                                                          |
| **Bayesian Framework**                                                                                                                      |                                                                                                                                                                              |                                                                                                                                                 |                                                                                              |
| $P(a < \theta < b) = 0.95$                                                                                                                  | $\theta$: parameter of interest (treated as a random variable).                                                                                                              | Used to define the **95% Credible Interval (CrI)** for a parameter $\theta$ in Bayesian inference.                                              | 95% probability of the parameter $\theta$ lying within the interval $(a, b)$.                |
