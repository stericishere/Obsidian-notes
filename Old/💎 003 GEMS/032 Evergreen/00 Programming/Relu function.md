## Relu function
- ReLU (max(0,x))
- Leaky ReLU (max(0.01x,x))
	- Introduces a small positive slope for negative inputs
- Parametric ReLU (PReLU)
	- the slope for negative inputs is learned
- Exponential Linear Unit (ELU)
	- faster learning
