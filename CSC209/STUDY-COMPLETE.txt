🚨 CRITICAL CONCEPTS (Study These Hard!)
─────────────────────────────────────────────────────────────────────────────

1. Memory Allocation Order
   ✓ Know what gets malloc'd when
   ✓ Understand scope & lifetime
   ✓ Know when it's destroyed

2. Free Sequence
   ✓ Free inner allocations before outer
   ✓ Set to NULL after freeing
   ✓ Never free twice

3. Safe String Functions
   ✓ strcpy = NEVER (no bounds)
   ✓ strncpy = ALWAYS (with bounds)
   ✓ strlen() excludes null terminator

4. Pointer Arithmetic
   ✓ p+1 scales by sizeof(type)
   ✓ a[i] == *(a+i)
   ✓ Difference is in elements, not bytes

5. Deep vs Shallow Copy
   ✓ Shallow = copy pointers (WRONG for structs)
   ✓ Deep = allocate new memory and copy data (RIGHT)

6. Permission Bits
   ✓ r=4, w=2, x=1
   ✓ User | Group | Others
   ✓ Convert octal ↔ symbolic instantly
