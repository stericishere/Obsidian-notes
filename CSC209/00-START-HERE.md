## 💡 Pro Study Tips

### ✅ DO THIS
- **Read Deep Dives FIRST** - understand concepts before memorizing APIs
- **Run code locally** - write small test programs for each concept
- **Use valgrind** - check memory issues as you practice
- **Mark progress** - use checkboxes to track what you know
- **Review man pages** - `man 2 fork`, `man 3 malloc`, etc.
- **Understand not memorize** - Know WHY, not just HOW

### ❌ AVOID THIS
- Don't just memorize function signatures
- Don't skip common pitfalls section
- Don't test only happy paths (test errors!)
- Don't ignore return values
- Don't forget to reap zombie processes
- Don't call printf() in signal handlers
