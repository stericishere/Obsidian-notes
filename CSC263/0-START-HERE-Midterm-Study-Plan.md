## 🚨 Final Exam Tips

### Mistakes to Avoid (from analysis of past exams)

❌ **Height Definition Confusion**
- Define height at exam start (nodes vs. edges)
- Stick to it consistently

❌ **Forgetting Rotations Preserve BST Property**
- Yes, they do. Always. Check if you rotate correctly.

❌ **Single Rotation When Double Needed**
- Same-sign BF = single
- Opposite-sign BF = double
- Memorize and execute this rule carefully

❌ **Indicator Variable Mistakes**
- X_i ∈ {0,1} always, not a count
- E[X_i] = P(event i occurs)

❌ **Heap Property Confusion**
- Heap is NOT fully sorted
- Only parent ≥ children (max-heap)
- Median could be anywhere in heap

❌ **Forgetting SUHA for Hashing**
- O(1) only under Simple Uniform Hashing Assumption
- Worst-case is still O(n)
